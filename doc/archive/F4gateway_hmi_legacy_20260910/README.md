# Legacy F4gateway HMI archive — 2026-09-10

These files were removed from the active F4gateway source/test tree because they describe the superseded HOME/CAMERA/GPS/ACTUATOR direct-navigation UI and one-tap latched motion behavior.
The production renderer is now UiShell/UiMenu/TouchButtons with OVERVIEW, ESC, PERCEPTION, NAVIGATION, SYSTEM and dead-man hold/release motion semantics.
This archive is reference-only and is not part of the firmware build.
